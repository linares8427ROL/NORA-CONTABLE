# Nora Contable

App de control de gastos de tarjeta que funciona 100% offline.

## Características

- Registro de gastos con descripción, monto, tarjeta y fecha
- Múltiples tarjetas con colores personalizados
- Ciclo de facturación con fecha de corte configurable
- Historial con búsqueda y filtros
- Reconocimiento de voz (requiere HTTPS)
- Copia de seguridad exportar/importar JSON
- 100% offline - funciona sin internet

## Instalar en Android

1. Abre la app en Chrome Android
2. Toca los 3 puntos (menú)
3. Selecciona "Agregar a pantalla de inicio"
4. Confirma - ¡Nora se instala como app!

## Tecnologías

- HTML5 / CSS3 / JavaScript vanilla
- IndexedDB (base de datos local)
- Service Worker (funciona offline)
- Web Speech API (reconocimiento de voz)
- PWA (Progressive Web App)
